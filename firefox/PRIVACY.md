# Privacy Policy — KZT to RUB Converter

**Last updated:** September 30, 2026

## Overview

KZT to RUB Converter is a browser extension that automatically converts prices from Kazakhstani tenge (₸) to Russian rubles (₽).

## Data Collection

The extension does not collect, store, sell, or transmit personal information or user data.

The extension does not collect:

* Personal information
* Browsing history
* IP addresses
* Authentication information
* Cookies
* Website content for tracking purposes
* Analytics or telemetry data

## External Requests

The extension may request current exchange-rate information from:

https://www.cbr-xml-daily.ru/

These requests are used solely to obtain currency exchange-rate data required for the conversion from KZT to RUB.

No personal information is intentionally sent to this service by the extension.

## Local Storage

The extension may use the browser's storage API to save extension settings or cached exchange-rate information.

This information remains within the browser and is not transmitted to the extension developer.

## Third-Party Services

The extension does not use third-party analytics, advertising, tracking, or user profiling services.

## Changes to This Privacy Policy

If the extension's functionality changes in a way that affects user data or privacy, this privacy policy will be updated accordingly.

## Contact

For questions regarding this privacy policy, please contact the extension developer through the project's GitHub repository.
